# E-LAPOR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a complete, multi-role campus grievance and whistleblowing web application (E-LAPOR) for Universitas Airlangga campuses (Mojo, Sobo, Giri) supporting authenticated service reports and anonymous whistleblowing with hierarchical disposition and verification.

**Architecture:** Monolithic Laravel 13 application utilizing Blade templates, Tailwind CSS for institutional modern styling, and Alpine.js for lightweight interactive modals and dynamic tab filtering. Relational data model enforcing strict departmental hierarchy, role boundaries, and audit trail of dispositions.

**Tech Stack:** PHP 8.3+, Laravel 13, MySQL / SQLite (in-memory for tests), Tailwind CSS, Alpine.js, PHPUnit.

**Spec:** [`docs/superpowers/specs/2026-10-31-e-lapor-system-design.md`](file:///d:/ALL%20PROJECT/E_LAPOR/docs/superpowers/specs/2026-10-31-e-lapor-system-design.md)

---

## Global Constraints

- **Platform Framework**: Laravel 13.x on PHP 8.3+.
- **Valid Email Domain**: Reporter registration strictly limited to `@unair.ac.id`.
- **Campus Locations**: Fixed enum: `mojo`, `sobo`, `giri`.
- **System Roles**: Fixed enum: `pelapor`, `kabag`, `kasubag`, `petugas`.
- **Authority Boundary**: Kabag cannot directly assign Kasubag's officers; Kasubag officers can only be assigned by their respective Kasubag.
- **Whistleblowing Secrecy**: Whistleblowing reports are exclusively accessible by Kabag; Kasubag and Petugas have zero visibility.

---

## Review Focus

1. **Non-UNAIR email registration**: Attempting to register with `user@gmail.com` must fail validation with a specific error message.
2. **Kabag authority boundary violation**: Attempting to dispose a sub-department report directly to a Petugas belonging to a Kasubag must be rejected by backend validation.
3. **Whistleblowing data isolation**: Kasubag or Petugas attempting to view, query, or count Whistleblowing tickets must receive 403 Forbidden.
4. **Petugas Kabag revision routing**: A revision issued by Kabag on work done by Petugas Kabag must not fail on `kasubag_id` foreign key and must route directly back to Petugas Kabag.
5. **Rating restrictions on non-terlaksana / rejected reports**: A reporter cannot submit a 1–5 star rating for tickets with status `ditolak` or execution result `tertunda`.

// tests/Feature/E2EReportLifecycleTest.php
namespace Tests\Feature;

use Illuminate\Foundation\Testing\RefreshDatabase;
use Illuminate\Http\UploadedFile;
use Illuminate\Support\Facades\Storage;
use Tests\TestCase;
use App\Models\User;
use App\Models\SubDepartment;
use App\Models\Report;

class E2EReportLifecycleTest extends TestCase
{
    use RefreshDatabase;

    public function test_complete_report_lifecycle_flow(): void
    {
        Storage::fake('public');

        $sarpras = SubDepartment::create(['name' => 'Sarana Prasarana', 'code' => 'SARPRAS']);
        $kabag = User::factory()->create(['role' => 'kabag']);
        $kasubag = User::factory()->create(['role' => 'kasubag', 'sub_department_id' => $sarpras->id]);
        $petugas = User::factory()->create(['role' => 'petugas', 'sub_department_id' => $sarpras->id]);
        $pelapor = User::factory()->create(['role' => 'pelapor', 'email' => 'pelapor@unair.ac.id']);

        // 1. Pelapor submits report
        $this->actingAs($pelapor)->post('/pelapor/laporan', [
            'title' => 'Gedung Mojo Bocor',
            'campus_location' => 'mojo',
            'sub_department_id' => $sarpras->id,
            'description' => 'Bocor di lantai 2',
        ]);
        $report = Report::latest()->first();
        $this->assertEquals('diajukan', $report->status);

        // 2. Kabag disposes to Kasubag
        $this->actingAs($kabag)->post("/kabag/laporan/{$report->id}/disposisi", [
            'target_type' => 'kasubag',
            'receiver_id' => $kasubag->id,
            'notes' => 'Segera cek lapangan.',
        ]);
        $this->assertEquals('didisposisi', $report->fresh()->status);

        // 3. Kasubag disposes to Petugas
        $this->actingAs($kasubag)->post("/kasubag/laporan/{$report->id}/disposisi", [
            'receiver_id' => $petugas->id,
            'notes' => 'Bawa alat tambal.',
        ]);
        $this->assertEquals('diterima', $report->fresh()->status);

        // 4. Petugas starts work
        $this->actingAs($petugas)->post("/petugas/laporan/{$report->id}/mulai");
        $this->assertEquals('proses', $report->fresh()->status);

        // 5. Petugas finishes work
        $this->actingAs($petugas)->post("/petugas/laporan/{$report->id}/selesai", [
            'notes' => 'Sudah ditambal rapi.',
            'execution_result' => 'terlaksana',
            'evidence' => UploadedFile::fake()->image('bukti.jpg'),
        ]);
        $this->assertEquals('verifikasi_kabag', $report->fresh()->status);

        // 6. Kabag approves verification
        $this->actingAs($kabag)->post("/kabag/verifikasi/{$report->id}/approve", [
            'notes' => 'Pekerjaan baik.',
        ]);
        $this->assertEquals('selesai', $report->fresh()->status);

        // 7. Pelapor provides rating
        $this->actingAs($pelapor)->post("/pelapor/laporan/{$report->id}/rating", [
            'rating' => 5,
        ]);
        $this->assertEquals(5, $report->fresh()->rating);
    }
}
